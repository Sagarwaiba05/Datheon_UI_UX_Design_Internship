UI/UX Design Internship — Datheon

About the Project

This repository contains my completed UI/UX design assignments as part of the Datheon UI/UX Design Internship.

The projects demonstrate my understanding of mobile application design, design systems, reusable components, user experience principles, and interactive prototyping using Figma.

Completed Tasks

Task 1 —  Mobile Wallet Flow Redesign

Goal: Design clear financial workflows.

Designed a mobile wallet interface called PayFlow, focusing on:

- Balance overview and dashboard.
- Peer-to-peer money transfer.
- Recipient selection.
- Transaction history.
- Consistent visual hierarchy and financial information presentation.

Tools: Figma

Figma Design Link:(https://www.figma.com/design/1eVwGb3AYiaZuavYIdy4Rm/Untitled?node-id=0-1)

 Task 2 — Design System & Component Library

Goal: Build modular reusable UI tokens.

Created a reusable design system based on the PayFlow visual identity, including:

- Color palette and color styles.
- Typography scale.
- Primary and secondary buttons.
- Button variants using Auto Layout.
- Text input and search field components.


Tools: Figma

Task 3 — Interactive E-Commerce Checkout Prototype

Goal: Prototype micro-interactions and transitions.

Designed a mobile e-commerce checkout experience called ShopEase, including:

- Shopping cart.
- Product quantity controls.
- Delivery address selection.
- Payment method selection.
